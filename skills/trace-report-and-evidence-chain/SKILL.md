# 溯源报告与证据链

## 适用条件

- 取证与处置阶段已完成，需要结案：输出时间线、证据索引、IOC、处置记录与未决问题。
- 需要对外（上级单位/通报单位/使用人）出具材料，或需要让人能**独立复核**结论。
- 交付形态可能是 Markdown 简报、HTML 证据链图、Word 报告（公文格式）。

产出物固定四件（缺一件视为未结案）：**报告正文**、**证据索引（路径 + SHA-256）**、**证据链示意图**、**样本/证据归档包**。

## 证据要求

- 报告中**每一条结论都要能指到证据**：`证据编号 → 采集主机 → 采集时间（含时区）→ 命令/来源 → 原始输出或文件路径 → SHA-256`。
- 事实、推断、待验证**三分**，用不同标记呈现；推断必须写依据与置信度，禁止把推断写成事实。
- 原始输出不要"美化"：命令与返回原文照录，长文本截取要标注截取位置。
- 涉及他人个人信息（聊天记录、浏览记录、账号）时：**只保留与失陷判定相关的最小片段**，其余不写入报告。
- 身份标识口径（按组织惯例）：`内网IP-学号（或工号）` 与 `出口NAT公网IP` 成三元组，例如 `<10.x.x.x>-<学号> 出口 <公网IP>`；同一活动多台主机时并列列出，便于横向关联。
- 对外交付物**不得写入己方调查/分析机自身的 IP 与活动**（分析机只写"分析终端"）。

## 工具顺序

1. **归集证据**：把各阶段采集的原始输出、样本哈希、日志行区间、截图按主机与时间归档到 `<case-dir>/证据/<主机>/`。
2. **校验完整性**：对归档包生成清单 `sha256sum -c` 可验证的 `SHA256SUMS`（Windows：`Get-FileHash` 输出为 `清单_sha256.txt`）；报告里写明清单文件位置。
3. **重建时间线**（唯一权威版本）：
   - 时间（含时区）→ 事件 → 证据编号 → 置信度；
   - 排序规则：以可信时间源为准（事件日志/文件系统时间/日志服务器），主机本地时间偏差要在报告里说明；
   - 时间线至少覆盖：投毒载体出现 → 文件释放 → 持久化建立 → 首次外联 → 后续动作（横向/加密/外传）→ 处置动作。
4. **IOC 清单**：类型（文件哈希/域名/IP:端口/URL/注册表项/计划任务名/服务名/互斥量）→ 值 → 首次出现时间 → 来源（哪台主机、哪个证据）→ 是否已处置。
5. **画证据链示意图**：用泳道或时间轴呈现"受害者主机 ← 投毒载体 ← 分发来源 → C2 / 外传去向"，节点标注时间与证据编号；深色 16:9 或普通流程图均可，但**必须能不看正文就说明问题**。
6. **写报告正文**：固定章节 —— 概述（谁、什么时候、什么症状）、调查范围与方法、**落地时间线与证据**、IOC 清单、影响面与损失评估、处置过程与结果、复验结论、未决问题与建议、附录（证据索引、命令清单、样本清单与哈希）。
7. **格式落地**：
   - Markdown：标题层级清晰，时间线与 IOC 用表格；
   - HTML：单文件、内嵌样式、可直接双击打开；
   - Word（若需要公文格式）：正文用仿宋_GB2312、标题用方正小标宋简体、数字与字母用 Times New Roman，**每个 run 都要设置 `sz` 与 `eastAsia` 字体**，否则出现字号/字体错乱；生成后务必通读抽查空格与换行。
8. **定级与表述**：对调查中顺带发现的系统缺陷（例如无需认证即可读取敏感信息的接口、明文口令、暴露的调试端点），按组织口径**至少中危**起评，写清复现证据与修复建议；不夸大、不写没有证据支撑的影响。

## 停止条件

- 四件产出物齐备且证据可复核 → 结案。
- 存在未决问题（证据缺失、无法定位入口、影响范围无法界定）→ 在报告中**显式列为未决**，不要用模糊表述掩盖。
- 结论与证据冲突（例如处置后发现外联仍在）→ 回到调查阶段，不强行结案。

## 输出格式

```
一、概述：主机（内网IP-学号 出口NAT）、时间窗、症状、结论一句话
二、调查范围与方法：连接方式、权限、只读/审批动作边界、工具与技能
三、落地时间线（表）：时间(含时区) | 事件 | 证据编号 | 置信度
四、IOC 清单（表）：类型 | 值 | 首次出现 | 来源主机 | 处置状态
五、影响面：数据、账号、业务、是否外传（证据支撑）
六、处置过程：动作 | 命令 | 时间 | 审批人/记录 | 结果 | 是否可回滚
七、复验结论：处置后重采结果（进程/持久化/外联/安全软件状态）
八、未决问题与建议
九、附录：证据索引（编号-路径-SHA256）、命令清单、样本清单
```

## 红线与审批

- 只读：读取与归档证据、生成哈希、撰写报告 → 直接执行。
- 需审批：报告中包含个人信息范围的决定、对外通报内容、样本外发。
- 禁止：编造/补写未采集到的证据；把推断写成事实；在对外材料中泄露他人隐私、己方分析机信息或与事件无关的数据。
