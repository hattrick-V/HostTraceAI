# HostTraceAI 平台说明

HostTraceAI 是面向授权运维与安全响应的 AI 主机溯源平台。

## 调查闭环

```text
目标主机 → 连接校验 → AI 对话调查 → MCP/SSH 采集 → 证据归档
       → 专家分析 → 审批处置 → 时间线 → 报告
```

## 领域对象

- 主机：调查对象及其连接信息，不是测绘资产。
- 任务：一次有明确目标和范围的溯源调查。
- 证据：命令输出、事件日志、网络连接、文件哈希和样本。
- 发现：木马、WebShell、后门、挖矿、异常持久化等调查结论。
- 动作：采集、打包、隔离、阻断、终止等可审计操作。
- Skill：面向某类主机行为的调查知识和工具选择规则。

## 专家角色

指挥官负责理解目标并调度专家；病毒木马专家负责主机持久化和样本分析；WebShell 专家负责 Web 目录、脚本、上传文件和后门行为分析。

## 数据存储

平台沿用成熟 SQLite 迁移机制。对话、任务和溯源元数据存入主库，技能知识存入知识库，原始样本和证据包保存在 `data/artifacts/<task>/<host>/`，数据库只保存路径、大小、哈希和权限信息。
